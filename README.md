# 🚀 TaskNova - AI Education Task Organizer

## 📌 Description
TaskNova is an AI-powered education task organizer designed to help students manage their academic workload efficiently. It prioritizes tasks based on urgency, importance, and learning impact to improve productivity and time management.

---

## ✨ Features
- Smart dashboard (To Do, In Progress, Completed)
- AI-based task prioritization
- Reminders and alarms
- Progress tracking
- User authentication (Login/Signup)
- Dynamic study planning

---

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript, React
- Backend: Node.js
- Database: MySQL, MongoDB

## ⚙️ Installation & Setup

1. Clone the repository
```
git clone https://github.com/Srishti620/tasknova.git
```

2. Navigate to project folder
```
cd tasknova
```

3. Install dependencies
```
npm install
```

4. Run the project
```
npm start
```
