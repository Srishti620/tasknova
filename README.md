# 📚 Overview

TaskNova is an AI-powered task management platform built to help students organize assignments, prioritize study sessions, and stay productive.

Instead of treating every task equally, TaskNova intelligently categorizes work based on urgency, importance, and learning impact, making it easier to focus on what matters most. Smart task prioritization can help learners better organize workloads and reduce the feeling of being overwhelmed. :contentReference[oaicite:0]{index=0}

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Srishti620/tasknova.git
```

Navigate to the project

```bash
cd tasknova
```

Install dependencies

```bash
npm install
```

Run the client

```bash
npm run dev
```

Start the backend server

```bash
npm start
```
